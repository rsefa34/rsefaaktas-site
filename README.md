# rsefaaktas.com

Portfolio site of Recep Sefa Aktaş — Camera Operator & AI Commercial Director.

- `public/` — everything that gets published
- `public/index.html` — site entry
- `public/assets/img/` — images, posters, thumbnails
- `public/assets/cv/` — CV PDFs (EN / TR)
- `public/assets/video/` — placeholder only; full videos are hosted on Cloudflare R2

Deployed with Cloudflare Workers (static assets, see `wrangler.jsonc`) from the `main` branch.
